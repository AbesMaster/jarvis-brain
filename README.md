# Jarvis Brain — the free starter from MetaMasterMindz

This is the **brain** — the memory half of a real AI chief of staff. Drop these files in, follow the steps, and your AI gets a real, persistent memory: a working Obsidian vault structure, a boot config, daily notes that write themselves, and a profile that updates as the AI learns about you. It lives outside the model with no size ceiling, and the AI only ever holds what the current task needs, pulling the rest back in one step.

**What this is not:** there are no agents, no skills, no automations, no hands in this repo. No voice, no board, no trading bots, no social posting pipeline. This is the architecture — Memory + Structure. The Hands (the actual agents and skills that turn this into an operator, not just a notetaker) are the next step up.

## Quick start

```
Already inside a Claude Code session? Paste this and it builds the whole system with you:
"I'd like to set this up, please."
```

Or run [`ai-memory-vault.md`](ai-memory-vault.md) directly — it checks whether Obsidian is installed (installs it if not), interviews you, then builds the folder structure, boot config, daily notes, and a profile that keeps itself current.

Starter files are in [`templates/`](templates/) — every `[FILL IN: ...]` marker is a spot the AI fills in with you.
